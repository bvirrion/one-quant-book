# 29. Build: An Order-Book Model, End to End — brief and source ledger

## Brief

- **Hook.** The book's last model is small on purpose: a forecast of the next few seconds of the mid price, trained on the simulator's sessions, validated without leaks, compiled into a few microseconds, and traded in the same simulator, where every microsecond it takes is a microsecond of stale decisions.
- **Sections.** The specification; Data, labels and validation; The model and its compiled form; Trading it in the simulator; What the latency costs.
- **Defines.** decision staleness.
- **Uses (defined earlier).** exchange simulator (B10.26), agent-based model (B10.27), maker-taker pricing (B1.9), queue position (B7.18), latency model (B7.18), mark-out curve (B7.23), sim-to-live reconciliation (B7.19), short-horizon alpha (B11.7), latency budget (B13.1), triple-barrier label (ch2), gradient boosting (ch5), temporal convolutional network (ch8), inference latency (ch26), quantisation (ch26), model monitoring (ch27), handoff specification (ch28), purging (B7.20), embargo (B7.20), label overlap (B7.20), walk-forward analysis (B7.20), combinatorial purged cross-validation (B7.20), model artefact (ch25), feature store (ch24), training--serving skew (ch24), model registry (ch25), limit order book (B10.1), order-flow imbalance (B7.8), queue imbalance (B7.8), microprice (B7.8), mid price (B1.1), bid--ask spread (B1.1), trade sign (B7.9).
- **Tutorial.** End to end on Book 10's exchange simulator: generate training, validation and test sessions on disjoint seeds; build features through firm.featstore and labels through firm.labeling; validate with purged folds; train LightGBM and a small TCN; compile the chosen model with firm.mlinfer and check parity; trade it through the simulator's agent API with fees, queue-position fills and a decision delay equal to the measured inference latency plus Book 10's latency model; track the run in firm.exptrack and monitor it with firm.mlmonitor. Data: synthetic (Book 10's simulator; firm.tape until it is frozen).
- **Build.** `firm.lobmodel`: the whole pipeline as one reproducible firm.workflow graph -- sessions, features, labels, validation, model, compiled model (C++20 and Rust serving path with parity vectors), simulator agent with a decision-latency parameter, P&L and mark-out report; Python + C++20 + Rust.
- **Weekend problem.** Microseconds are money -- named result: net P&L per session and the one-second mark-out as functions of decision latency, and the latency at which the model's edge falls to zero.
- **Facts to verify.** Book 10's simulator documentation (internal, frozen at the sync); Kolm, Turiel and Westray 2023 (Mathematical Finance); Sirignano and Cont 2019; Cartea, Jaimungal and Penalva 2015 Algorithmic and High-Frequency Trading (Cambridge); Aquilina, Budish and O'Neill 2022 quantifying the high-frequency trading arms race (QJE): value of speed, cited only as context.
