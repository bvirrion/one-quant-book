## New traps and calibration (for the shared docs)

- dol.gov, www.sec.gov and bls.gov all refuse scripted downloads (403); the Internet Archive's `id_` URLs serve the
  original bytes. SEC's `efts` and `data.sec.gov` accept a plain research user agent.
- Companies House documents come as image PDFs for some filings; ask for `format=xhtml` first. For large firms'
  full accounts only the image PDF exists (tiff2pdf, no text layer, no tesseract here): render the page with
  `pdftoppm -r 80` and read it; `scratchpad/industry/montage.py` tiles pages (numpy + zlib, no PIL) to find them.
- The Internet Archive serves some files gzip-compressed without a header: check the magic bytes and gunzip.
- `www.sec.gov/Archives` refuses a plain research UA; its archived copies exist for some filings (a 2023 X-17A-5 did).
- ugrep (the `grep` here) rejects long regexes with `{0,260}` on UTF-8: use Python `re` (scratchpad `find.py`).
- iXBRL tags can carry the wrong sign (Quadrature 2025: other operating income tagged `sign="-"`): store as tagged,
  reconcile totals, and override only explicitly. Companies House image accounts give page refs; the iXBRL gives
  context ids -- both are locators in the snapshot.
- Staff costs per head of a group entity can be meaningless: a UK trading firm may book revenue in a company and
  employ everyone in an LLP (TUPE transfer), with most of the LLP's profit going to a corporate member.
- PDF comma scan after ch. 11: hits only inside direct quotations (ch. 1, 2, 3, 5, 9: ``more than 3,000'') and one
  ch. 3 parenthesis (2,100); fixed at once by typesetting quoted numbers with thin spaces (quotation typography,
  not wording). Literal display strings (an iXBRL tag's shown text) go in tested excerpt files and \omcode.
- pgfplots `boxplot` needs `\usepgfplotslibrary{statistics}`, which `onequant.sty` does not load (shared file):
  draw percentile ranges with explicit error bars read from the CSV instead.
- `pkill -f PATTERN` kills the calling shell when PATTERN appears in its own command line: kill by PID.
- Internet Archive copies of some 10-Ks are truncated at 1 MiB or refused (403); the headcount sentence may be missing.
- LCA derivation (decision 5) ran once on 2026-09-29 over FY2021 and FY2025 (eight quarterly files via the Internet
  Archive, 1.2 GB, about 12 minutes streamed under `nice -n 19` and a 2G/4G memory scope); kept rows cached in the
  scratchpad so tables can be rebuilt without re-reading. A second suppression rule was needed: cells from fewer than
  three employers (the single asset manager would otherwise have been published).
- The DOL page calls each disclosure file cumulative for the fiscal year, yet the quarterly files differ in size by
  a factor of three; deduplicating by case number makes either reading safe.
- A chart-CSV label with a comma ("forms, then SIC") broke pgfplots before `check_figdata.py` ran: strip commas in the
  figure script.
- Shared-module listing drift: adding docstring lines to `firm_roles.py` shifted ch. 16's listing by six lines and
  `make test-code` stayed GREEN (it checks that ranges exist, not what they show). Run `tools/omcode_ends.py` for every
  chapter that lists a shared module after each edit to it; from ch. 19 the module's docstring no longer grows.
- Index overfull vbox (6 pt, one-page index while `\output` is active) reappeared after ch. 18's entries: the known
  transient of WRITING section 9; recheck as later chapters add entries and in Phase C.
- pgfplots `xbar` with `nodes near coords` and `point meta=explicit symbolic`: the labels sit above the bar ends
  (overlapping the next bar) until `nodes near coords style={anchor=west}` is given; `nodes near coords align` did not help.
- `files.adviserinfo.sec.gov` brochure PDFs answer 404 to the plain research user agent and 200 to curl's default one
  (no e-mail involved either way); the IAPD search API accepts the research UA.
- pgfplots `ybar interval` treats the last row as the right edge of the previous bin: add a closing row, or the last bin
  disappears; set `x tick label as interval=false` for ticks at bin edges.
- EUR-Lex answers scripted requests with HTTP 202 and an empty challenge page, and the Internet Archive's newest copies
  are the same page; an older capture (2023 and before) holds the text.
- A constant `\addplot ... {1.2}` inside a `ybar` axis inherits a bar legend image; give it `legend image code` explicitly.
- The chapter gate's `drafty` check flags any literal `...`, including pgfplots tick ranges such as `{0,4,...,40}`: write
  the ticks out.
- HUD User (huduser.gov) and uscis.gov refuse scripts (202 challenge / 403); the Internet Archive holds the FMR workbook and
  the USCIS pages. RVD's historical tables are .xls (BIFF), which openpyxl cannot read: xlrd was installed into the
  scratchpad (`pip --target`), not the shared venv.
- Non-ASCII characters inside a listed source file stop pdflatex (`Invalid UTF-8 byte sequence` in listings): write
  them as escapes (`"\u00ef"`) in the code; the tests cannot catch it, only the build.
- Grouped (non-stacked) `ybar`/`xbar` legends draw two small bars per entry; `area legend` fixes it only when it comes
  *after* the `ybar` key in the axis options (the bar style resets the legend image). pgfplots' `legend cell align`
  defaults to centre, which misaligns multi-column legends: set `legend cell align=left` on every legend.
- Bars on a `ymode=log` axis grow from 1, so a value of 1 draws no bar: give `log origin=infty`.
- The 130 dpi crop washes thin coloured lines in a legend towards black; re-render at 300 dpi
  (`pdftoppm -r 300 -x -y -W -H`) before "fixing" a legend colour.
