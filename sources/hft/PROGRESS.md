## Conventions of this book

- Teaching modules `hf_*.py` in `code/hft/NN-slug/python/`; running project `code/firm/<component>/firm_<component>.py`.
- Every tutorial's strategy is a `Quoter` run through `firm.mmharness` (ch. 1): on Book 7's `firm_tape` agent API
  (`simulate(cfg, agent=...)`, `simulate_pair`) until Book 10's exchange simulator lands, then on the simulator
  through an adapter, with no change to the strategies. No private simulator (batch rule).
- Libraries: numpy, pandas, scipy, statsmodels (batch ruling 1). Tests deterministic, each chapter well under a
  minute; `OPENBLAS_NUM_THREADS=1`.
- Latencies printed in the book are either simulated (stated as such) or cited; never machine timings.
- Planted effects tuned to the public record (Book 8 trap); every rule rerun a tick (message) later (Book 9 trap);
  common random numbers across policies (Book 9 ch. 24's `flowmm` pattern: the mid path does not depend on the quoter).
- Firms named only with a ledger row (Virtu, Flow Traders, Knight Capital's SEC order, XTX only if sourced, …).
- Manipulation (layering, spoofing, sandwiching) is pointed to Book 9 ch. 29; ch. 10 and ch. 25 say where the line
  is and cite the enforcement record, with no operational recipe.
