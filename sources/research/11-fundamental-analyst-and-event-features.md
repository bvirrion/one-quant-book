# 11. Fundamental, Analyst and Event Features — brief and source ledger

## Brief

- **Hook.** A company closes its quarter on 31 December and files its report on 5 February. A database keyed on the period end lets a backtest trade the numbers five weeks before anyone could read them.
- **Sections.** Accounting data, point-in-time; Ratios as features; Surprises and revisions; Event calendars; Predictor cards.
- **Defines.** fiscal period, filing lag, trailing twelve months, accounting ratio, earnings surprise, standardised unexpected earnings, analyst revision, forecast dispersion, event calendar, announcement window.
- **Uses (defined earlier).** consensus forecast (B2.31), point-in-time data (ch3), restatement (ch3), knowledge time (ch3), as-of join (ch3), security master (ch4), predictor card (ch6).
- **Tutorial.** Pull a few companies' XBRL facts from SEC EDGAR (public), measure filing lags and detect restated periods; build trailing-twelve-month values and an earnings-surprise feature keyed on filing dates; then measure the IC inflation when the same features are keyed on period ends in firm.synthmkt.
- **Build.** `firm.fundpit`: fundamental feature builder keyed on knowledge time (as-reported values, TTM, ratios, SUE with seasonal random-walk expectation, revision and dispersion features) on top of firm.pit; Python.
- **Weekend problem.** The five-week head start — named result: the information-coefficient inflation of a SUE and a value signal when period-end dating replaces filing-date dating.
- **Facts to verify.** SEC periodic report deadlines by filer status (Form 10-Q, 10-K); SEC EDGAR XBRL companyfacts API (data.sec.gov); Ball and Brown 1968 (J. Accounting Research); Foster, Olsen, Shevlin 1984 SUE (Accounting Review); Bernard and Thomas 1989 PEAD (J. Accounting Research); Womack 1996 analyst recommendations (JF); Diether, Malloy, Scherbina 2002 dispersion (JF); Sloan 1996 accruals (Accounting Review).
