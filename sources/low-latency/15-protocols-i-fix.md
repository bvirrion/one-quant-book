# 15. Protocols I: FIX — brief and source ledger

## Brief

- **Hook.** An order sent from a fund to its broker this morning most likely travelled as a line of tag=value pairs whose format two firms agreed in 1992; the protocol is old, slow to parse naively, and everywhere.
- **Sections.** Tag-value encoding and the message; The session layer: logon, heartbeats, sequence numbers, resend and gap fill; The application layer: orders and execution reports; Parsing fast; Where FIX is still used.
- **Defines.** FIX protocol, tag-value encoding, FIX session, heartbeat, resend request, gap fill, FIX engine.
- **Uses (defined earlier).** sequence number (B1.28), execution report (B10.26), order lifecycle (B7.17), partial fill (B7.17), SIMD (ch14), direct market access (B1.4).
- **Tutorial.** Parse and build FIX 4.4 messages in C++ with zero-copy field views over the buffer, body length and checksum included; replay a recorded conversation with a gap through the session state machine and watch the resend request and the gap fill; compare parse throughput with a map-based parser. End state: a table of messages per second by parser, measured on this laptop, and the session trace.
- **Build.** `firm.fixengine`: tag-value codec (zero-copy views, checksum, body length), session state machine (logon, heartbeat, test request, resend request, sequence reset and gap fill, logout) and a message store for resends; C++20, Rust and a Python reference; golden conversations as fixtures.
- **Weekend problem.** The weekend gap -- named result: messages resent and time to resynchronise after a disconnect of a given length at a given message rate, with and without gap fill of administrative messages.
- **Data.** Golden FIX conversations written by the chapter's script (synthetic).
- **Facts to verify.** FIX Trading Community: history (1992, Fidelity and Salomon Brothers); FIX 4.4 and FIXT 1.1 / FIX 5.0 SP2 specifications: tags 8, 9, 35, 34, 49, 56, 52, 10, checksum and body length rules; FIX Performance Session Layer (FIXP) and FIX over SBE (dated); venues and brokers that offer FIX order entry today (dated).
