# 13. Linux Tuning — brief and source ledger

## Brief

- **Hook.** A thread that should have run without interruption was stopped for a few microseconds every few milliseconds, like a clock; it was the kernel's own timer tick, and the fix was a boot parameter.
- **Sections.** Core isolation and CPU affinity; Interrupts and their affinity; Tickless kernels and housekeeping; Busy polling and kernel bypass; Real-time priorities and memory locking.
- **Defines.** CPU affinity, core isolation, housekeeping core, interrupt affinity, tickless kernel, context switch, busy polling, kernel bypass, real-time scheduling policy, memory locking.
- **Uses (defined earlier).** jitter (ch1), page fault (ch6), time-stamp counter (ch2), device locality (ch4), NUMA node (ch4).
- **Tutorial.** Measure what this machine allows: a spinning thread that records every gap in its own time-stamp readings (a hiccup meter), alone, pinned, and next to a competing load; busy polling against a blocking receive on a loopback UDP socket; mlockall and the page-fault count. The isolation, interrupt and real-time steps are shown as the commands a tuned host runs, with what a reader would see there. End state: the gap histograms and the loopback receive latencies, measured on this laptop, no isolated cores.
- **Build.** `firm.tuneaudit`: audits a host against firm.coreplan's plan -- kernel command line, isolated and tickless CPU lists, interrupt affinities, frequency governors, idle-state limits, transparent huge pages, locked memory limits -- and reports each deviation; tested on fixture sysfs and procfs trees; Python.
- **Weekend problem.** The hiccup -- named result: the fraction of wall time a spinning thread is not running and its worst gap on this laptop, against a tuned host modelled from cited figures.
- **Data.** Measured on this laptop; synthetic sysfs/procfs fixtures for a tuned and a mis-tuned host.
- **Facts to verify.** Linux kernel documentation: kernel-parameters (isolcpus, nohz_full, irqaffinity, rcu_nocbs), timers/no_hz; Red Hat Enterprise Linux for Real Time tuning guide (dated); socket(7): SO_BUSY_POLL; sched(7); mlockall(2); a public description of kernel-bypass stacks (vendor or open-source documentation).
