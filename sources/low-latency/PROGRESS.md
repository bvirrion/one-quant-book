## Conventions of this book

- Teaching code: `code/low-latency/NN-slug/{python,cpp,rust,tests}`; Python modules `ll_*.py`; C++ files `ll_*.hpp`
  / `ll_*_test.cpp` (each `*_test.cpp` is compiled **alone** by `tools/test_code.sh` with `-std=c++20 -O2 -Wall
  -Wextra -Werror -I<its dir>`: code under test is header-only); Rust crates std-only (no crates.io dependency), one
  crate per chapter or component, `clippy -D warnings`.
- Running project: `code/firm/<component>/` with `cpp/firm_<component>.hpp` + `_test.cpp`, `rust/` crate
  `firm_<component>`, and `firm_<component>.py` where there is a Python reference.
- **Measured timings** (user ruling): benchmarks are `bench_*.py` (Python drivers that build and run a C++/Rust
  bench) writing `figdata/low-latency/NN-slug/measured_*.csv` plus a `measured_*.meta` sidecar (machine, date, g++ /
  rustc versions, flags, `taskset` CPU list, load note). They are **not** `fig_*.py`, so `make figdata` does not rerun
  them and its no-diff rule still holds for every deterministic chart. Captions: "measured on a laptop (Intel Core
  Ultra 7 155H) under WSL2, no isolated cores". Tests assert only orderings, counts (allocations, page faults,
  gaps), and wide tail-to-median bounds. Re-run all benches in Phase C when the other three agents are idle (the batch
  loads the machine), and state that in the captions' data clause if not.
- Hardware facts of this machine (for captions and tutorials): 22 logical CPUs shown by WSL2 as 11 cores x 2
  threads (the 155H is 6 P-cores with SMT + 8 E-cores + 2 LP E-cores: the reported topology is not the real one —
  a teaching point for ch. 2 and 4); one NUMA node; L1d 48 KiB, L2 2 MiB per P-core, L3 24 MiB; `constant_tsc`,
  `rdtscp`; AVX2 but no AVX-512; THP in `madvise` mode; `perf_event_paranoid` = 2 and no `perf`; `taskset`
  and `chrt` exist; multicast on loopback works (tested: join 239.1.1.1 on 127.0.0.1, IP_MULTICAST_LOOP).
  g++ 11.4 does **not** auto-vectorise at -O2 (GCC 12 does): ch. 14 uses it.
- Assembly printed in ch. 2, 7, 8, 14: generated by a script from a tested source with `objdump -d -M intel`,
  committed as `.txt` (so `\omcode` prints it without a language), the compiler version named in the caption; a
  test checks properties of the disassembly (no `call` in the hot loop, a `vpcmpeqb` present), never bytes (CI's
  g++ differs from 11.4).
- Linker watch-list for Phase C: *latency* (one word, will need STOP), *sequencer architecture* vs B3's
  *sequencer*, *token bucket* vs B3's *token*, *heartbeat*, *failover*, *inlining*, *conflation*, *arena*.
