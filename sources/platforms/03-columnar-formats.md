# 3. Columnar Formats — brief and source ledger

## Brief

- **Hook.** A query for one symbol's average spread over an hour read a year of quotes, 4 GB, and took a minute; after the file was sorted by symbol and time and written in row groups with statistics, the same query read a few megabytes. Nothing about the data changed, only where its bytes sit.
- **Sections.** Rows against columns; The in-memory columnar standard: buffers, validity, dictionaries; The on-disk columnar standard: row groups, pages, encodings; Statistics and pushdown; Choosing a layout for market data.
- **Defines.** row-oriented layout, columnar layout, row group, column chunk, data page, dictionary encoding, run-length encoding, delta encoding, bit packing, validity bitmap, zone map, predicate pushdown, projection pushdown.
- **Uses (defined earlier).** structure of arrays (B13.14), cache line (B13.3), SIMD (B13.14), tick data (ch2), compression ratio (ch2), partitioning (ch2).
- **Tutorial.** Take one simulated day of trades and quotes for fifty symbols; inspect an Arrow record batch's buffers (validity bitmap, offsets, dictionary indices); write Parquet with different sort orders, row-group sizes and encodings, read its footer metadata with pyarrow, and measure the bytes and row groups a symbol-and-time filter touches with and without statistics. End state: a chart of bytes read against row-group size for sorted and unsorted files, and a table of encodings chosen per column.
- **Build.** `firm.colfile`: a minimal columnar file format written from scratch -- header, row groups, per-column chunks with plain, dictionary, run-length and delta-plus-bit-packed encodings, min/max statistics, and a reader that applies projection and predicate pushdown; acceptance: round trip of every column type and the same answers as pyarrow on the same data; Python (numpy).
- **Weekend problem.** Four gigabytes for one hour -- named result: the bytes read by a one-symbol, one-hour query against a year of quotes for three layouts (unsorted, sorted by symbol and time, partitioned by date and symbol), and the row-group size that minimises them.
- **Facts to verify.** Apache Arrow columnar format specification (buffers, validity bitmap, alignment to 64 bytes); Apache Parquet format specification (row groups, column chunks, pages, encodings, statistics); Abadi, Madden and Hachem 2008, Column-stores vs. row-stores (SIGMOD); Melnik et al. 2010, Dremel (VLDB): the nested-column encoding Parquet adopted.
- **Data.** Synthetic trades and quotes from firm.tape seeds (fifty symbols, one day), a few tens of MB generated by script.
