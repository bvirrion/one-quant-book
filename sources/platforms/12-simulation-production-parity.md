# 12. Simulation--Production Parity — brief and source ledger

## Brief

- **Hook.** A strategy that had passed its replay parity test started quoting a tick wider in production on its first morning: its timer fired on the machine's clock in production and on the simulated clock in the backtest, and the two disagreed about when the opening auction had ended.
- **Sections.** One strategy, several environments; Abstracting time; Abstracting market data; Abstracting order entry; The parity harness.
- **Defines.** simulation--production parity, strategy host, environment adapter, market-data abstraction, order-entry abstraction, parity harness.
- **Uses (defined earlier).** replay parity test (B7.19), shadow trading (B7.19), training--serving skew (B12.24), injected clock (B13.20), event loop (B13.20), deterministic replay (B13.23), input journal (B13.23), order gateway (B13.21), order state machine (B13.21), order-entry protocol (B10.26), backtest engine (ch11), event model (ch11).
- **Tutorial.** Host one strategy object in three environments -- the backtest engine, the exchange simulator in process, and a production-shaped path that talks the simulator's order-entry protocol over an in-memory byte stream through Book 13's gateway -- behind a clock, a market-data and an order-entry interface; journal the inputs of the production-shaped run and replay them into the other two; plant four parity defects (a wall-clock read, float prices, callback order on simultaneous events, acknowledgement semantics) and let the harness find each. End state: a table of defects against the first diverging order and the parity after the fixes.
- **Build.** `firm.strathost`: `Clock`, `MarketData`, `OrderEntry` protocols; adapters for the backtest engine, the in-process simulator and the protocol path; an input journal and replay driver (on Book 13's binlog record format); the parity harness comparing order sequences, fills and positions event by event with the first-difference report; Python.
- **Weekend problem.** The morning the timer fired -- named result: the number of events until each planted defect produces its first diverging order, the orders affected in a day, and zero divergence after the fixes on ten seeds.
- **Facts to verify.** a public account of a live-versus-backtest divergence caused by environment differences (engineering talk or paper, dated) or none (then the hook stays realistic, unsourced); Book 13's input-journal format (prose pointer).
