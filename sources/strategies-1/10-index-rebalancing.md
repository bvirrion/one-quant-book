# 10. Index Rebalancing — brief and source ledger

## Brief

- **Hook.** A stock is added to a major index and rises seven per cent between the announcement and the effective date; twenty years later the same event moves it by a fraction of that, because everyone predicts it.
- **Sections.** Index rules and the calendar; Predicting additions and deletions; Trading the event and the reversal; How the trade decayed.
- **Defines.** index fund, rank day, membership prediction.
- **Uses (defined earlier).** index reconstitution (B1.15), index effect (B1.15), buffer rule (B1.15), call auction (B1.13), price pressure (ch9), backtest (B7.16), vectorised backtest (B7.16), information coefficient (B7.6), transaction cost analysis (B7.23), capacity curve (B7.28), fundamental factor model (B7.24).
- **Strategy files.** predicted additions; predicted deletions; effective-date close liquidity provision; post-event reversal.
- **Tutorial.** Write a rank-based reconstitution rule with banding for firm.synthmkt, predict membership changes from data before the rank day, simulate index-fund demand at the close, and trade predicted additions and deletions with their reversal.
- **Build.** `firm.indexevent`: index rules (rank day, banding, float adjustment), membership prediction with probabilities, and event-time trading with close-auction demand; Python.
- **Weekend problem.** Everyone predicts it — named result: the prediction accuracy of membership changes and the event return as index-tracking demand grows relative to arbitrage capital.
- **Facts to verify.** Shleifer 1986, Do demand curves for stocks slope down? (JF); Harris and Gurel 1986 (JF); Chen, Noronha, Singal 2004 (JF); Patel and Welch 2017, Extended stock returns in response to S&P 500 index changes (Review of Asset Pricing Studies); FTSE Russell reconstitution methodology (dated); S&P DJI index methodology (dated).
