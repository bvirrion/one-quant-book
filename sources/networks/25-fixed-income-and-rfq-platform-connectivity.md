# 25. Fixed-Income and Request-for-Quote Platform Connectivity — brief and source ledger

## Brief

- **Hook.** On a request-for-quote platform the client's quote timer runs for seconds, not microseconds; yet dealers answer in milliseconds, because a response that arrives late is not a worse price but no price at all, and because some clients execute the first acceptable answer automatically.
- **Sections.** Platform interfaces; Auto-responding: the pipeline from request to answer; Latency that matters when the clock is a quote timer; The interdealer order books.
- **Defines.** quote timer, automated execution rule.
- **Uses (defined earlier).** request for quote (B2.22), dealer-to-client platform (B2.04), inter-dealer broker (B2.04), all-to-all trading (B2.22), auto-quoting (B11.22), win-probability model (B11.22), cover price (B11.22), FIX session (B13.15), latency budget (B13.1), colocation (ch9).
- **Tutorial.** Model an RFQ's timeline from arrival to response through a pricing pipeline with a latency distribution (firm.latbudget stages), and a client's automated execution rule that takes the first acceptable price; compute the probability of missing the timer and of losing to a faster, equally priced dealer, with Book 11's win-probability model, and compare the value of a millisecond with the value of a basis point. End state: win probability against response time for two client behaviours.
- **Build.** `firm.rfqlink`: an RFQ connectivity model -- sessions, timers, throttles, the auto-responder's pipeline stages and a timer-compliance check, client rules (best price at expiry, first acceptable), with Book 11's firm.rfqmm pricing wrapped; Python. Consumed by chapter 29.
- **Weekend problem.** Two seconds to answer -- named result: the probability of missing the quote timer at a given pipeline latency distribution, and the share of business lost to a faster dealer under a first-acceptable execution rule.
- **Facts to verify.** platform documentation of RFQ protocols and response windows (Tradeweb, MarketAxess, Bloomberg) where public (dated); a platform's automated execution rules product description (dated); BrokerTec and Nasdaq Fixed Income colocation or data-centre location (dated).
- **Data.** Parameters stated; simulation labelled.
