# 18. Private Connectivity to Crypto Venues — brief and source ledger

## Brief

- **Hook.** A venue that runs in a public cloud can offer its market makers a private endpoint inside the provider's network: their orders never touch the public internet, and never cross a zone boundary if the endpoint sits in the same zone as their machines -- which the zone identifiers of chapter 16 let them check.
- **Sections.** Virtual networks, peering and private endpoints; Venue colocation offers; Cross-connects at data-centre-hosted venues; Dedicated and market-maker gateways, and the tiers that unlock them.
- **Defines.** virtual private cloud, virtual-network peering, private endpoint, network load balancer.
- **Uses (defined earlier).** cloud region (B3.26), availability zone (ch16), availability-zone identifier (ch16), colocation (ch9), cross-connect (ch9), proximity hosting (ch9), dedicated endpoint (B3.25), tier matching (B3.25), rate limit (B3.15), WebSocket (B13.17), FIX session (B13.15), TLS handshake (B13.17), data-transfer charge (ch16).
- **Tutorial.** A labelled simulation with hop latencies and prices from cited documentation: compare the public-internet path (TLS to a public endpoint), a private endpoint in the same zone and in another zone, and virtual-network peering; check the endpoint's zone identifier against the instance's, and price each path per million messages. End state: a path-latency chart and a cost table per million messages.
- **Build.** `firm.privlink`: a private-path planner -- a venue's documented connectivity options as data (public, private endpoint by zone, peering, colocation cross-connect; dated rows), the firm's firm.cloudplan placement, a zone-alignment check, expected latency and monthly cost per path; Python. Consumed by chapter 29.
- **Weekend problem.** The endpoint in the wrong zone -- named result: the added latency and data-processing cost per million messages of a private endpoint served from another zone against the same zone.
- **Facts to verify.** AWS PrivateLink documentation and pricing (endpoint-hour, per-GB, cross-zone) (dated); AWS VPC peering documentation; AWS Network Load Balancer cross-zone behaviour; crypto venues' published private connectivity, colocation or cross-connect offers (dated box, each row sourced); Book 3's dated box on dedicated endpoints and market-maker programmes (pointer).
- **Data.** Documentation rows (dated); simulations labelled.
