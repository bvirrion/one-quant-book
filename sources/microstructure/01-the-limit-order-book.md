# 1. The Limit Order Book — brief and source ledger

## Brief

- **Hook.** A trader sends a buy order for 500 shares at 100.02 and the screen shows 3,000 shares already bid there. Her order is not at the best bid: it is behind a line of orders that arrived first, and it trades only if that line is consumed before anyone cancels or the price moves away.
- **Sections.** State: price levels and queues; Events: add, cancel, modify, execute; Priority and what resets it; The book as a data structure; The book as a queueing system.
- **Defines.** limit order, market order, limit order book, tick size, price level, order-book event, matching engine, zero-intelligence model.
- **Uses (defined earlier).** order (B1.4), exchange (B1.4), bid--ask spread (B1.1), mid price (B1.1), price-time priority (B1.19), market-by-order (B1.19), market-by-price (B1.19), level 1 (B1.28), level 2 (B1.28), level 3 (B1.28), sequence number (B1.28), market data feed (B1.4), queue position (B7.18), cancellation rate (B7.8), depth profile (B7.8), Poisson process (B4.6), birth--death process (B4.8), continuous-time Markov chain (B4.8).
- **Tutorial.** Rebuild the book of a firm.tape session message by message with firm.lob; measure the event mix, order lifetimes and the time the best quotes survive; check a price-indexed array book against a tree-keyed book on the same messages (identical level 2 at every step); then run the Smith-Farmer zero-intelligence model on firm.lob and compare its spread and depth with the tape's. Data: firm.tape (simulated).
- **Build.** `firm.lob`: the reference limit order book (order map, price levels with FIFO queues, add / cancel / reduce / modify with the priority rules of the chapter, execute, level-1/2/3 views, an invariant checker) in Python, with a C++20 and a Rust twin that reproduce the Python book on a shared message fixture; the core that chapter 26's matching engine is built on.
- **Weekend problem.** The line at 100.02 -- named result: the probability that a resting order at the back of the best bid fills before the price moves, in the zero-intelligence model and in the simulated market, against queue length.
- **Facts to verify.** Gould, Porter, Williams, McDonald, Fenn, Howison 2013 limit order books (Quantitative Finance); Smith, Farmer, Gillemot, Krishnamurthy 2003 statistical theory of the continuous double auction (QF); Cont, Stoikov, Talreja 2010 a stochastic model for order book dynamics (Operations Research); Nasdaq TotalView-ITCH 5.0 order replace and cancel semantics (dated); CME Globex / Nasdaq rules on priority after a size decrease or increase (dated).
